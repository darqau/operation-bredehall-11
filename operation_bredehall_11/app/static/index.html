      Så sparas din data

      All ekonomi och alla uppgifter ligger i en databasfil (bredehall.db) som följer med i git. Du behöver inte importera CSV igen när Home Assistant uppdateras.

      Samma data överallt

      • Datorn (127.0.0.1:8890) läser filen direkt i projektmappen.
      • Home Assistant / Tailscale (port 8765) får samma fil automatiskt vid omstart efter git-uppdatering.

      Rutin när du ändrat något

      1. Jobba som vanligt på datorn.
      2. Stoppa den lokala servern (Ctrl+C i terminalen) innan du sparar till git. Medan appen kör håller den databasen öppen — då kan git inte få med hela innehållet. Ibland skapas också tillfälliga sidofiler (.db-wal, .db-shm); de försvinner när servern stoppats och allt skrivits in i huvudfilen.
      3. Commit och push till GitHub (filerna data/bredehall.db och data/finance_config.json ska följa med).
      4. I Home Assistant: uppdatera add-on → Återuppbygg → Starta om.

      Tänk på

      • Ändringar du bara gör via mobil/Tailscale hamnar inte automatiskt i git — gör ekonomiändringar på datorn om du vill att de ska följa med till nästa uppdatering.
      • Databasen innehåller riktiga transaktioner — repot ska vara privat.
      • API-nyckeln under nedan sparas i webbläsaren och behövs för Tailscale (samma värde som app_api_key i add-on-konfigurationen).
      • Stäng (uppe till höger) stoppar den lokala servern — syns bara när du kör appen på datorn (127.0.0.1 / Start Bredehall.exe).
